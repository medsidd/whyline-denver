Under the Colorado Open Records Act, I request copies of the following public records, in electronic, machine-readable form (CSV or Excel preferred; PDF only if no other format exists):

1. **Boardings by route and month.** Total boardings (and average weekday, Saturday and Sunday boardings, if kept) for each bus and rail route, for each month from January 2025 to the most recent month available.

2. **Boardings and alightings by stop.** Average weekday boardings and alightings at each stop, by route if kept, for the most recent service period for which automatic passenger counter (APC) data has been processed. Please include the stop ID used in RTD's GTFS feed and the dates the period covers.

3. **Bus stop amenities.** RTD's current inventory of amenities at each stop, such as shelter, bench, trash receptacle, lighting, real-time sign and ADA boarding pad, with the GTFS stop ID.

4. **On-time performance methodology.** Any manual, procedure or specification describing how RTD calculates the on-time figures in its monthly Bus and Rail Operations reports: which stops are measured, arrival or departure, the first and last timepoint, whole-minute rounding, missing AVL data and other exclusions, and how the monthly figure is aggregated.

If a record exists only in a different but similar form (for example, boardings by route for each service change rather than each month), please provide that instead of withholding it.

I'm not requesting any personally identifiable information. If any part of a record must be withheld or redacted, please release the rest and cite the exemption that applies to what is withheld.
